# pkg-graph-visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов Ubuntu (apt).
Получает данные о зависимостях напрямую из репозитория — без `apt`, `dpkg`
и сторонних библиотек для работы с пакетами.

Реализовано:

- **Этап 1** — CLI-прототип с конфигурацией и валидацией параметров.
- **Этап 2** — сбор прямых зависимостей пакета из `Packages.gz`.
- **Этап 3** — построение графа зависимостей (DFS без рекурсии),
  обработка циклов и режим тестирования на файле описания графа.

## Требования

- Python 3.9+
- Интернет — только для режима `--mode remote` (этап 2).

## Установка

```bash
python -m venv .venv
source .venv/bin/activate        # Linux / macOS
.venv\Scripts\activate           # Windows
pip install -r requirements.txt
```
